# 油猴脚本：汉化质检 & 快进

`mw-i18n-helper.user.js` —— 一个自包含的用户脚本，用来**快速推进度**并**顺手收集漏翻**。

## 为什么能做「快进」

游戏用 Vue，根组件挂在 `body` 上，而它的根数据里就放着游戏本体：

```js
document.body.__vue_app__._instance.proxy.$data
//   .universal  ← 就是游戏内部的 IUniversal（资源、五棵树、远征、宝物、地狱…）
//   .training   ← 训练
```

所以脚本能**直接改运行时状态**，点一下立刻生效，不用改存档、不用刷新。

## 安装

1. 装 [Tampermonkey](https://www.tampermonkey.net/)（Violentmonkey 也行）
2. 打开脚本管理面板 → 新建脚本 → 把 `mw-i18n-helper.user.js` 整个粘进去 → 保存
3. 打开游戏页面，右下角会出现「汉化质检 / 快进」面板

默认匹配：`*.github.io`、`localhost`、`127.0.0.1`、`file://`。
如果你在别的域名上玩，自己在脚本头部加一行：

```js
// @match        https://你的域名/*
```

> 用 `file://` 直接打开的话，需要到扩展详情里勾选「允许访问文件网址」。

## 怎么用

快捷键 **Alt + M** 收起 / 展开。面板可拖动。

| 分组 | 按钮 | 作用 |
| --- | --- | --- |
| 资源 | `×10` / `×1e6` / `×1e10` | 把 40 多个货币字段一起放大（不含 `*R`/`*Size` 这类结构字段，不然游戏会按 1e40 个格子循环） |
| 资源 | 点亮全树 | 五棵树所有节点 `active/unlocked=true`、`level=10` |
| 资源 | 解锁子系统 | 自动化、远征、宝物、熔炉、矿场 |
| 进度 | 宇宙 +10 / =200 | 宇宙层数（很多界面按它解锁） |
| 进度 | 训练拉满 | 训练等级 100、总量 1e30（力量的主要来源） |
| 进度 | **一键全做** | 以上全部 |
| 时间 | ×1 / ×2 / ×5 / ×10 | 时间加速（见下） |
| 质检 | 扫描一次 | 立刻扫一遍当前界面 |
| 质检 | 导出 JSON | 把累计的漏翻导出成文件 |
| 质检 | 清空累计 | 重置统计 |
| 存档 | 备份 / 恢复 | 动存档前先备份，后悔了能回去 |

## 漏翻是怎么收集的

脚本加载后会自动调用 `I18N.collectMissing(true)`，之后**你正常玩就行**，所有没命中的原文会被记下来。两个来源互补：

- **引擎未命中**：`I18N.getMissing()` —— i18n 引擎每次查词条失败都会记一笔
- **页面残留**：直接扫 DOM 文本节点 + `title/placeholder/alt/aria-label`，兜住「只翻译了一半」的碎片（引擎认为它已经命中，不会记录）

面板上的数字是累计条数，随时可以导出：

```json
{
  "total": 12,
  "items": [
    { "kind": "dom", "text": "Slime multiplies Essence ×", "count": 3, "where": ["#content2_6_upgrade3_name"] }
  ]
}
```

`where` 是最近的带 id 祖先，方便定位到具体面板。

导出后把 JSON 发给译者（或者直接丢给我），补进 `i18n/locales/zh-CN.js` 就行。

## 时间加速的原理与副作用

游戏每帧用 `Date.now()` 的差值算进度，所以脚本把时钟按倍数调快：

```js
Date.now = () => virtBase + (realNow() - realBase) * factor;
```

副作用是存档里的 `lastTick` 会跑到未来，重开时会多算一段离线收益。脚本已经在写存档时把它改写回真实时间：

```js
Storage.prototype.setItem = function (key, value) {
  if (key === 'GameSave' && factor !== 1) { /* 把 IGameData.lastTick 改回 realNow() */ }
};
```

所以随便加速、随便关，存档不会因为时间穿越而炸掉。**但加速期间别手动改系统时间**，那会真的乱。

## 已知限制

- **力量（Power）和精华（Essence）改不了**：它们在 `IGameData` 里，不在 Vue 的 `data` 上，脚本够不着。靠「训练拉满」让它们自然涨。
- **挑战者等级 / 狩猎等级改不了**：同理，在 `IFight` 里。这两个卡着「狩猎」「飞升」两个页签，需要的话用仓库里的 `saves/graduation.json` 直接导入。
- 恢复备份后会强制刷新一次。这是必要的——游戏在页面隐藏时会把当前状态写进 `GameSaveOff`，脚本得在刷新前把它拦掉，否则恢复的内容会被旧状态盖回去。
